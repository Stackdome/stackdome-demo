You deployed three containers. web serves this page. redis holds a queue. worker has no url at all — it just watches the queue and does what it finds there.

Pressing Celebrate doesn't run the animation. It writes a job to redis, the worker picks it up, and the result comes back to every browser that has this page open.

Everything on this page is read from environment variables. Edit .env before you deploy, or change them on the stack and redeploy.

# .env
CELEBRATION=confetti     # confetti | lasers | balloons | kisses
HAT=party              # party | cap | crown | beanie
HEADLINE=Your stack is now live.
WORKER_REPLICAS=1      # raise it, then hold the button down
  • The worker reads these at startup, so a redeploy is what applies them.
  • Set WORKER_REPLICAS to 3 and every job is claimed by a different worker.
  • Delete the worker container and press Celebrate — the jobs wait in redis until it comes back.
